# 🛒 MarketScan

> Умный поиск товаров по интернет-магазинам с возможностью сравнения предложений в одном интерфейсе.

MarketScan — это веб-приложение для поиска товаров сразу по нескольким интернет-магазинам и маркетплейсам.

Пользователь вводит название нужного товара, после чего поисковый запрос отправляется на backend. Сервер обрабатывает запрос через единый API-сервис для поиска товаров и возвращает найденные предложения. Полученные данные отображаются в удобном интерфейсе, где пользователь может сравнить товары, цены и перейти непосредственно на сайт продавца.

Проект создан с целью упростить поиск выгодных предложений и избавить пользователя от необходимости вручную искать один и тот же товар на разных площадках.

---

## ✨ Возможности

- 🔎 Поиск товаров по пользовательскому запросу
- 🛍️ Сбор предложений из различных интернет-магазинов и маркетплейсов
- 📊 Отображение результатов в едином интерфейсе
- 💰 Сравнение цен на найденные товары
- ⭐ Отображение рейтинга и количества отзывов, если данные доступны
- ↕️ Сортировка товаров по цене
- 🔗 Переход непосредственно на страницу товара в магазине
- ⏳ Индикатор загрузки во время выполнения поиска
- ⚠️ Обработка ошибок при недоступности сервера или проблемах с запросом
- 📱 Адаптивный интерфейс для разных устройств
