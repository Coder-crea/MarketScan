# 🛒 MarketScan

> Умный поиск товаров по интернет-магазинам и маркетплейсам с возможностью сравнения предложений в одном интерфейсе.

MarketScan — это веб-приложение для поиска товаров сразу по нескольким интернет-магазинам и маркетплейсам.

Пользователь вводит название необходимого товара, после чего поисковый запрос передаётся на backend. Backend обрабатывает запрос с использованием внешнего API-сервиса поиска товаров и получает предложения из различных источников.

Полученные данные возвращаются во Frontend и отображаются в едином интерфейсе в виде карточек товаров. Пользователь может просмотреть характеристики доступных предложений, сравнить цены, ознакомиться с рейтингом и количеством отзывов, отсортировать результаты и перейти непосредственно на страницу товара в магазине.

Основная идея MarketScan — избавить пользователя от необходимости вручную искать один и тот же товар на разных площадках и предоставить возможность быстро изучить доступные предложения в одном месте.

## 🎯 Цель проекта

MarketScan создан для упрощения поиска и сравнения товаров в интернете.

Обычный процесс поиска товара может выглядеть следующим образом:

```text
Пользователь хочет купить товар
        ↓
Открывает первый интернет-магазин
        ↓
Выполняет поиск
        ↓
Запоминает или сравнивает цену
        ↓
Открывает второй интернет-магазин
        ↓
Повторяет поиск
        ↓
Сравнивает результаты

MarketScan объединяет этот процесс в единый сценарий:

Пользователь вводит один поисковый запрос
        ↓
React Frontend отправляет запрос на Backend
        ↓
Backend обрабатывает поисковый запрос
        ↓
Backend обращается к внешнему API-сервису поиска
        ↓
Получаются предложения из различных источников
        ↓
Результаты возвращаются на Frontend
        ↓
Пользователь получает единый список предложений
        ↓
Сравнивает цены и выбирает подходящий вариант

Приложение построено по принципу взаимодействия:

Frontend → Backend → Внешний API-сервис → Источники товаров
