# 🛒 MarketScan

> Умный поиск товаров по интернет-магазинам и маркетплейсам с возможностью сравнения предложений в одном интерфейсе.

## 📌 О проекте

**MarketScan** — веб-приложение для поиска товаров сразу в нескольких интернет-магазинах и маркетплейсах.

Пользователь вводит название нужного товара, после чего поисковый запрос отправляется на Backend. Backend обрабатывает запрос с помощью внешнего API-сервиса поиска товаров и получает предложения из различных источников.

Полученные данные возвращаются на Frontend и отображаются в едином интерфейсе в виде карточек товаров. Пользователь может посмотреть цену, рейтинг и количество отзывов, отсортировать найденные предложения и перейти непосредственно на страницу товара в магазине.

Основная идея проекта — избавить пользователя от необходимости вручную искать один и тот же товар на разных площадках и предоставить возможность быстро найти и сравнить доступные предложения в одном месте.

## 🎯 Цель проекта

Основная цель MarketScan — упростить процесс поиска товаров и сравнения предложений в интернете.

Вместо того чтобы открывать несколько интернет-магазинов и выполнять один и тот же поиск вручную, пользователь может ввести запрос один раз и получить результаты в едином интерфейсе.

🔎 Как работает поиск
1. Пользователь вводит поисковый запрос

Например:

Кроссовки Adidas

После ввода запроса пользователь запускает поиск.

Приложение формирует URL с поисковым параметром:

/search?q=Кроссовки%20Adidas

Использование URL-параметра позволяет сохранять поисковый запрос и корректно обрабатывать переходы между страницами приложения.

2. Frontend получает поисковый запрос

React-компонент получает значение параметра q из URL:

const query = searchParams.get("q") || "";

После получения запроса приложение проверяет его наличие и запускает процесс поиска.

3. Frontend отправляет запрос на Backend

React Frontend отправляет асинхронный HTTP-запрос на Backend API.

Пример запроса:

GET /api/search?q=Кроссовки%20Adidas

Запрос выполняется с использованием Fetch API:

const response = await fetch(
  `${API_URL}/search?q=${encodeURIComponent(searchQuery)}`,
  {
    method: "GET",
    headers: {
      "Content-Type": "application/json",
    },
  },
);

Для корректной передачи поискового запроса используется encodeURIComponent, который кодирует специальные символы и пробелы в URL.

4. Backend обрабатывает запрос

Backend получает поисковый запрос от Frontend и передаёт его внешнему API-сервису поиска товаров.

Внешний API-сервис используется для получения предложений товаров из различных интернет-магазинов и маркетплейсов.

После обработки запроса Backend получает результаты и возвращает их Frontend-приложению.

5. Frontend получает результаты

После получения ответа от Backend приложение обрабатывает данные и сохраняет результаты в состоянии React-компонента.

setResults({
  query: data.query || searchQuery,
  results: data.results || [],
  originalResults: data.results || [],
});

После обновления состояния React автоматически обновляет интерфейс и отображает найденные товары.

🛍️ Отображение товаров

Каждый найденный товар отображается в виде отдельной карточки.

Карточка товара может содержать:

🖼️ Изображение товара
📝 Название товара
💰 Цену
🏪 Название магазина или источника
⭐ Рейтинг
💬 Количество отзывов
🔗 Ссылку на страницу товара

Пример отображения списка товаров:

{products.map((product, idx) => (
  <div key={product.id || idx} className="product-card">
    ...
  </div>
))}

Приложение проверяет наличие данных перед их отображением. Например, рейтинг показывается только в том случае, если он присутствует в полученном ответе:

{product.rating && (
  <div className="product-rating">
    <span>⭐ {product.rating}</span>
  </div>
)}
💰 Сравнение предложений

MarketScan позволяет быстро сравнить найденные предложения в одном интерфейсе.

Например:

Кроссовки Adidas

Магазин 2 — 15 490 ₽

Пользователь может изучить доступные варианты, выбрать подходящий товар и перейти непосредственно на страницу продавца.

↕️ Сортировка результатов

Для удобной работы с большим количеством найденных товаров реализована сортировка результатов.

Доступные варианты:

По умолчанию
По цене — от дешёвых к дорогим
По цене — от дорогих к дешёвым
По рейтингу

Перед сортировкой создаётся копия исходного массива результатов:

const sorted = [...products];

Это позволяет не изменять оригинальный массив данных.

Для получения отсортированного списка используется useMemo:

const sortedResults = useMemo(() => {
  if (!results?.originalResults) return [];

  return sortProducts(
    results.originalResults,
    sortBy,
    sortOrder
  );
}, [
  results,
  sortBy,
  sortOrder,
  sortProducts
]);
⏳ Состояние загрузки

Поиск товаров может занимать некоторое время. Во время выполнения запроса приложение отображает состояние загрузки.

Например:

Ищем товары по запросу "Кроссовки Adidas"...

Для управления состоянием загрузки используется React State:

const [loading, setLoading] = useState(false);

Пользователь видит, что запрос обрабатывается, и понимает, что приложение выполняет поиск.

⚠️ Обработка ошибок

В приложении предусмотрена обработка ошибок на разных этапах работы.

Пустой поисковый запрос

Если пользователь не ввёл запрос, приложение предлагает ввести название необходимого товара.

Введите поисковый запрос
Ошибка HTTP-запроса

Если Backend возвращает ошибочный HTTP-статус, приложение фиксирует ошибку:

if (!response.ok) {
  throw new Error(`Ошибка ${response.status}`);
}
Ошибка соединения с сервером

Если Backend недоступен или соединение с сервером было прервано, пользователь получает соответствующее уведомление:

Сервер не отвечает. Проверьте подключение
Повторный поиск

После возникновения ошибки пользователь может повторить поисковый запрос.

🔗 Переход на страницу товара

Если для найденного товара доступна ссылка, пользователь может перейти непосредственно на страницу соответствующего предложения в магазине.

<a
  href={product.url}
  target="_blank"
  rel="noopener noreferrer"
>
  Перейти в магазин
</a>

Страница магазина открывается в новой вкладке браузера.

Таким образом, MarketScan используется как единая точка поиска и сравнения предложений, после чего пользователь может перейти непосредственно к продавцу.
